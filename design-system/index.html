Principles

A shared system for Blupi, SwatchBook and the apps that come after them. Bold frames, calm insides: the Bauhaus outline and offset shadow give each section presence, and everything inside stays quiet so content leads.

  1. One strong frame per sectionCards get the heavy outline and offset shadow. Inside them, use hairlines and spacing, never boxes inside boxes.
  2. One loud action per sectionA single framed button per section. Secondary actions are ghost buttons or icon buttons that stay grey until hovered.
  3. Uppercase is for structure, not contentSection titles, labels and buttons are uppercase and tracked. Names, descriptions and data stay in sentence case.
  4. Colour means somethingStatus, AI, danger and the brand accent. Neutrals do everything else.
  5. Each app keeps its own accentApps share shapes, type and spacing, and override only the brand tokens: Blupi's blue and yellow, SwatchBook's indigo.

Using it

Each app gets its own copy, one CSS file generated for its brand, so it deploys independently. Re-run the sync after changing the design system.

cd claude-sandbox/design-system
node scripts/sync.mjs ../inspo-browser/public/ds.css swatchbook

Then link it and opt the page in:

<link rel="stylesheet" href="ds.css">
<body class="ds-root ds-page">            <!-- add data-theme="dark" on <html> for dark -->

React and Tailwind apps can use the same classes, or map Tailwind colours to the tokens with tailwind-preset.cjs.
